# B2B 外贸客户背调情报分析师（通用版 / b2b-lead-intel）

一个面向**中国制造工厂 / 品牌商海外获客**的通用型销售情报分析技能。把一条原始客户线索（官网 / 公司名 / 公开资料 / 询盘 BOQ）转化为一份**可直接指导销售的决策报告**：排雷（识别皮包公司、空壳站）+ 决策链测绘（找对人）+ 5 维度 100 分制开发优先级评级 + 7 天破冰行动清单。

> 本技能为**行业通用框架**，已剔除任何特定行业、品牌、客户的私有信息。使用时请按你所在行业填入「产品库」与「认证补充区」。

## 核心能力

- **8 阶段工作流**：全域检索排雷 → 客户类型定位 → 业务基本盘画像 → 决策链/KP 测绘 → 产品线契合度 → 准入认证门槛 → 5 维 100 分制评级 → 7 天行动清单。
- **⚡ 客户速览卡（Snapshot）**：报告最顶部一张表，10 秒抓住重点（公司历史 / 主营产品 / 主营业务 / 主要渠道 / 服务区域 / 客户等级 + 一句话结论）。
- **5 维度 100 分制评级**：采购能力·潜力(25) / 市场·产品匹配度(25) / 公司资质·风险(20) / 合作深度·意向(20) / 履约·执行(10)，含评分明细表与 A/B/C/D 评级。
- **决策链测绘**：把"一个公司"拆成"一组人"（拍板人/影响者/守门人/使用者），按渠道类型给出触达顺序，并标注"KP 缺失"风险。

## 适用人群

- 做外贸 / 出海 B2B 销售、需对海外买家 / 经销商 / 工程方做背景调查与开发策略的团队。
- 任何行业的中国制造供应商（机械、电子、建材、消费品、食品接触、医疗等均可），只需替换产品库与认证即可。

## 安装（WorkBuddy）

将整个 `b2b-lead-intel/` 文件夹放入 WorkBuddy 的技能目录：

- Windows：`%USERPROFILE%\.workbuddy\skills\b2b-lead-intel\`
- macOS / Linux：`~/.workbuddy/skills/b2b-lead-intel\`

重启或刷新 WorkBuddy 后，对该技能说"分析 XX 客户 / 客户背调"即可触发。

> 也可直接 `git clone` 本仓库到上述路径。

## 使用前必做（重要）

技能内置的 `references/` 是**可填写模板**，不含任何具体行业数据：

1. **`references/product_competitors.md`** — 填入你司的【产品库 / 技术规格 / 竞品地图】。阶段 5 产品线契合度分析依赖它。
2. **`references/cert_matrix.md`** — 在「行业专属认证区」填入你行业的【强制 / 高关注认证】（如建材、电子、食品接触等各有专属）。阶段 6 准入门槛判定依赖它。

未填这两项时，阶段 5/6 的判定会是空的——这是设计使然，确保不泄露也不臆造行业数据。

```
└── LICENSE
```

## 触发方式

- 直接说：分析 [客户官网 URL / 公司名+国家]、客户背调、潜在客户开发策略、梳理决策链 / KP、竞品分析。
- 技能会自动联网检索 + 推理，输出带速览卡的结构化报告。

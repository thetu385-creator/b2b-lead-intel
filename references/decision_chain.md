# B2B 决策链测绘参考库（通用版）

> 用途：阶段 4「决策链测绘」对照表。目标是把"一个公司"拆成"一组人"，并判断先敲谁、后敲谁。
> 铁律：只找到一个联系人 ≠ 完成测绘。单点联系人是最大的丢单风险源。

## 一、四类角色定义（每条线索都要尝试填满）

| 角色 | 英文 | 判别特征 | 他真正关心的 | 给他什么弹药 |
|------|------|----------|--------------|--------------|
| **拍板人 DM** | Decision Maker | 能签字、能决定预算与品牌切换 | 利润率、风险、公司战略 | 商务条款、独家/返点、TCO 测算、工厂实力 |
| **影响者 INF** | Influencer | 技术/质量把关，有一票否决权 | 认证合规、参数达标、失效风险 | 认证证书包、检测报告、规格对照表、样品 |
| **守门人 GK** | Gatekeeper | 前台、客服、info@ 邮箱、助理 | 不惹麻烦、按流程走 | 简短专业的转介请求，别推销 |
| **使用者 USR** | User | 仓管、工地施工、安装队 | 好用、不出错、售后快 | 使用视频、工具配套、质保承诺 |
| **内线 CHP** | Champion | 愿意在内部替你说话的人 | 个人业绩、少踩坑 | 让他好看的材料：对比表、试单成功案例 |

> **测绘完成度判定**：找齐 DM + INF = 合格；只找到 GK = 未完成，必须标注「KP 缺失，建议补充检索」；找到 CHP = 优秀，评级可上浮。

## 二、按客户类型的典型链条构成

| 客户类型 | 链条长度 | 核心 DM | 关键 INF | 常见职位英文别名（LinkedIn 检索用） |
|----------|----------|---------|----------|-------------------------------------|
| Distributor 经销商 | 短（1–2 层） | Owner / Managing Director / General Manager | Product Manager、Category Manager | `Managing Director`, `Owner`, `Commercial Director`, `Purchasing Manager`, `Category Manager` |
| Wholesaler 批发商 | 中（2 层） | Purchasing Director | Category Buyer、Quality Manager | `Category Buyer`, `Head of Procurement`, `Branch Manager`, `Supply Chain Manager` |
| Retailer 零售商 | 极短（1 层） | Store Owner / Buyer | 无（老板兼） | `Owner`, `Buyer`, `Merchandising Manager` |
| Contractor 工程承包商 | 长（3–4 层） | Procurement Manager / Commercial Manager | MEP Engineer、QS 造价师 | `MEP Manager`, `Project Manager`, `Procurement Engineer`, `Quantity Surveyor`, `Site Engineer` |
| Builder 建筑商/开发商 | 长（3–4 层） | Development Director / Head of Procurement | Technical Director | `Development Director`, `Technical Director`, `Head of Procurement`, `Project Director` |
| Designer/Consultant | 中（2 层） | Design Manager / Partner | MEP Engineer、Specification Manager | `MEP Design Engineer`, `Specification Manager`, `Associate Director`, `Building Services Engineer` |
| OEM/ODM 代工 | 中（2–3 层） | Sourcing Director | QA Manager、Product Development Manager | `Sourcing Manager`, `Global Sourcing Director`, `QA Manager`, `Product Development Manager`, `Compliance Manager` |

## 三、四大主力渠道的链条差异与触达顺序

### 1. 东南亚经销商（印尼/马来/泰国/越南/菲律宾）
- **链条**：老板（华人家族企业居多）→ 采购/仓库主管。通常 1–2 层，老板即 DM。
- **特点**：决策快、看关系与价格弹性；家族成员可能不在官网出现，但握实权。
- **触达顺序**：直接找老板（WhatsApp 优先）→ 老板指派采购对接细节。
- **陷阱**：官网 info@ 常年无人看；纯邮件触达命中率极低，必须拿到手机号走 WhatsApp。
- **本地认证 INF 关注点**：当地强制认证（如 SNI/SIRIM 等）是硬门槛，会由采购直接卡。

### 2. 重合规市场（澳/欧/北美）品牌商 / OEM
- **链条**：Sourcing Manager（DM，主导商务）→ **Technical / Compliance Manager（INF，一票否决）** → QA。
- **特点**：**本地强制认证是否决项，不是加分项**。合规过不了，价格再好也归零。
- **触达顺序**：**先过 Compliance，再谈商务**。开局就主动附认证证书与测试报告，能直接跳过 60% 的拉锯。
- **陷阱**：只对 Sourcing 谈价格，Technical 一轮否决就前功尽弃。首封信必须技术+商务双抄送。

### 3. 中东 + 北非工程渠道（四层链，最复杂）
```
业主 Client/Employer  →  设计顾问 Consultant  →  总包 Main Contractor  →  机电分包 MEP Subcontractor
   定预算/品牌倾向         写规格书 spec           控成本/工期              实际下单采购
```
| 层级 | 角色定位 | 关键动作 | 典型机构举例 |
|------|----------|----------|--------------|
| **业主** | 最终 DM | 批准 approved vendor list | 政府部委、地产开发商、酒店集团 |
| **设计顾问/设计院** | 最强 INF | 撰写 specification，决定是否写 "or approved equal" | 区域大型顾问公司 |
| **总包** | 成本 DM | value engineering 换料，比价 | 本地大型承建商 |
| **机电分包** | 执行 USR/采购 | 询价、下单、进场 | 中小 MEP 公司 |

- **触达顺序（关键洞察）**：**规格前置（spec-in）**。必须在设计阶段进入顾问的 specification，才可能在招标时被列名。
- **判断你进得晚不晚**：如果只找到 MEP 分包在询价 → 项目已进比价阶段，你只能拼价格，利润极薄。若能接触到设计顾问 → 有机会做成指定品牌。
- **spec 中最值钱的一句话**：能否争取到 "or approved equal"（允许同等替代）。若规格锁死竞品型号，此单基本放弃。
- **陷阱**：中东项目常有代理制门槛，外资供应商需本地代理/保荐方可投标，测绘时须确认这一层是否存在。

### 4. 欧洲批发商
- **链条**：Category Buyer（DM）→ Quality / Compliance（INF，否决权）→ 采购委员会（大型连锁）。
- **特点**：流程化、决策慢（3–9 个月）、重文档与可追溯；CE/CPR 的 DoC 声明是入场券。
- **触达顺序**：Category Buyer 建立接触 → 提交完整合规文档包 → 进入年度供应商评审窗口。
- **陷阱**：欧洲有明确的采购季与评审窗口，错过窗口要等下一年度。测绘时应主动确认其 supplier review cycle。

## 四、KP 检索方法（阶段 4 执行手段）

1. **官网**：`/about`、`/team`、`/contact`、`/management` 页；查看新闻稿署名与引语（引语人通常是 DM）。
2. **LinkedIn 检索式**：
   - `site:linkedin.com/in "公司名" (purchasing OR procurement OR sourcing)`
   - `site:linkedin.com/in "公司名" ("managing director" OR owner OR CEO)`
   - `site:linkedin.com/in "公司名" (MEP OR "technical manager" OR compliance)`
3. **展会名录**：参展商名录常列出到场人员姓名与职务，是拿 DM 姓名最快的路径。
4. **海关数据**：提单上的 contact person 往往是实际下单的采购经办人（USR/采购），可作为切入 CHP 的对象。
5. **邮箱格式推断**：从已知一个邮箱推断公司格式（`first.last@` / `finitial+last@`），再用验证工具校验，避免硬退信。
6. **工程项目**：查项目新闻稿、招标公告，能定位到业主与设计顾问名称，再回到 LinkedIn 找具体人。

## 五、风险预警规则（必须写进报告）

| 情形 | 预警等级 | 处置建议 |
|------|----------|----------|
| 只找到 info@ / 通用邮箱，无任何具名 KP | **高** | 标注「决策链未测绘」，评级下调一档；Day 1 动作改为"找人"而非"卖货" |
| 只接触到 Gatekeeper | 中 | 用转介话术要人，不做产品推销 |
| 家族企业但官网只列职业经理人 | 中 | 提示实际拍板人可能是未公开的家族成员 |
| 工程项目仅接触到 MEP 分包 | 中高 | 提示已进入比价末端，评估是否值得投入 |
| 重合规市场客户未识别出 Compliance 角色 | **高** | 合规否决风险未评估，须补充检索 |
| 决策链跨国（如中东买家总部在欧洲） | 中 | 明确采购权在哪国，避免敲错门 |

| INF | | | | 第 2 步 | |
| GK | | | | 绕过/借力 | |

# 销售执行话术库 · 确认问题 & 7 天行动清单

> 用途：阶段 7「Sales Action Plan」的弹药库。所有问题/话术必须结合线索实际背景改写，禁止原文照搬、禁止空泛。

## 一、3 个核心确认问题（Qualification Questions）设计原则

每个线索输出 3 个针对性问题，分别刺探：
- **Q1 需求/采购量级**：确认其真实采购规模与品类缺口。
- **Q2 认证/规格门槛**：确认其市场准入硬约束（避免白做）。
- **Q3 决策链/合作模式**：确认 KP、采购节奏、是否独家/分销意向。

### 分类型问题库（改编示例，[方括号]按行业替换）

**Distributor 经销商**
1. 贵司目前代理/经营哪些[品类]品牌？年采购规模大致多少？哪些品类是缺货或想替换的？
2. 目标市场是否需要 [本地认证，如 CE/UL/区域强制认证 等]？现有供应商能否覆盖？
3. 是否有意洽谈区域独家分销？期望的起订量、账期与品牌支持（样品/目录/展会展位）是什么？

**Wholesaler 批发商**
1. 当前 [品类] 现货主要走哪些品牌与价格带？哪些 SKU 周转最快？
2. 对报价响应速度和最小起订量(MOQ)的要求？能否接受混批？
3. 是否愿意先小批量试单（如 1-2 个柜）验证品质与交期？

**Retailer 零售商**
1. 门店/线上主要卖什么规格的[产品]？终端客户最关心价格还是使用便利？
2. 是否接受混批小单？偏好哪种物流（快递/拼箱）？
3. 是否需要贴牌或自有包装以匹配你们渠道？

**Contractor 工程承包商**
1. 近期有无在建/拟建项目用到 [产品]？项目体量大概多少？
2. 项目对认证（[CE/UL/行业专属] 等）和检测报告的具体要求？
3. 付款节点如何安排（预付款/进度款/验收）？交期要求多紧？

**Builder 建筑商/开发商**
1. 贵司项目常用哪类[系统/产品]？是集中采购还是分包采购？
2. 对综合成本与系统配套（[产品+配件+服务]）的方案兴趣如何？
3. 是否有集采框架或年度协议意向？

**Designer/Consultant 设计/顾问**
1. 设计项目中倾向哪种[产品系统]？技术参数上最看重什么？
2. 是否需要我司产品技术手册、选型库或样品供设计参考？
3. 后续是否可推荐我司进入其指定品牌清单？

**OEM/ODM 代工**
1. 代工产品是 [品类] 中的哪类？有无自有模具或需我司开模？
2. 对产能、品控体系、批次一致性的具体要求？
3. 是否需签保密协议(NDA)？知识产权与品牌归属如何约定？

## 二、7 天行动清单模板（按类型微调）

### Day 1（精准触达）
- **渠道**：官网邮箱发开发信 + LinkedIn/WhatsApp 双触点（依地区习惯）。
- **切入点**：以"补齐品类缺口/认证覆盖/价格替代"为钩子，附 1 页产品概览 + 同类市场案例。
- **邮件主题公式**：`[自有品牌] Reliable [品类] supply for [国家/品类] – [客户名]`
- **CTA**：请求 15 分钟通话或回复 3 个确认问题。

### Day 3（价值跟进）
- **价值传递**：发送针对性资料——认证证书包（对应其市场）、规格对照表、或竞品替代成本测算。
- **痛点刺激**：点出其现有供应链潜在风险（交期/认证/价格），给出 [自有品牌] 解法。
- **CTA**：提供免费样品或报价单，邀请索取。

### Day 7（意向探底）
- **抛钩子**：限时样品免费、首单 MOQ 优惠、或区域保护意向试探。
- **探底话术**：「我们本季度在该区域计划发展 1-2 家核心伙伴，若贵司有意可优先谈独家/返点」。
- **判定**：有回复且问价/要样品 → 升 B 级跟进；无回复 → 转 C 级（月度触达），换触点再试。

## 三、常见异议与应对（阶段 7 备用）

| 客户异议 | [自有品牌] 应对话术方向 |
|----------|----------------------|
| 价格比现有供应商高 | 算总拥有成本(TCO)：质保年限、售后赔付、运输损耗；强调批量/年框折扣 |
| 没听过这个品牌 | 展示出口案例、合作中的国际买家、认证清单；先寄样品建立信任 |
| 认证不全 | 明确补证周期/费用；先用通用市场（如 CE）切入，再补区域强制认证 |
| MOQ 太高 | 提供混批方案、首单小批量试单、拼箱物流 |
| 担心质量/交期 | 开放工厂视频验厂、提供批次检测报告、明确交期违约条款 |
| 已有稳定供应商 | 定位"第二供应商/补充线"，主打备份与议价筹码价值 |

## 四、邮件/社媒触点建议（按区域）
- 欧洲：LinkedIn + 公司邮箱，专业克制，重认证与标准。
- 中东：WhatsApp + 邮箱，重响应速度与人情维系，展会后跟进最佳。
- 东南亚/中亚：WhatsApp/WeChat + 邮箱，重性价比与 MOQ 弹性。
- 北美：邮箱 + LinkedIn，重认证与合规文档。
- 非洲：WhatsApp + 邮箱，重现货与账期灵活。

## 五、专项场景：OEM / 白牌代工（竞品反向采购）

当线索**自身就是制造商**（自有品牌）却向我们采购同类产品 = 竞品工厂反向采购。核心姿态：**不做其自有品牌的替代者，定位「第二货源 / 白牌代工 / 成本优化补充线」**。

**3 个确认问题**
1. 贵司自有 [产线] 此次采购用于 自有品牌补货 / 白牌代工(OEM) / 贸易转售 / 项目配套？期望品牌呈现（中性白牌 / 贴贵司标 / 用 [自有品牌] 标）？
2. 按什么标准/规格？压力/功率/接口等关键参数？是否需特定区域认证以便转口？
3. 单品量级属于 季度备货还是单批？MOQ、交期、付款（LC at sight / TT / 账期）？是否接受小批量试单后放量？

**7 天行动清单**
- Day 1：邮件 + WhatsApp 双发，立场话术——"We are your reliable 2nd-source / white-label partner, NOT competing with your brand." 附型录 + 体系/产品认证 + 白牌包装方案 + FOB 价格区间。
- Day 3：发 production capability sheet（规格/参数/产能/交期）+ 白牌包装样例图；点出"自产 SKU 多、换线频繁、小批量不经济 → 我们专做大批量标准件更便宜更稳"；邀免费样品（Top SKU）。
- Day 7：抛钩子（首单 MOQ 弹性 + 样品免费 + 优先排产）；探底话术邀视频看产线敲定试单 SKU 与包装。

## 六、专项场景：政府 / 国际资助招标项目

当 BOQ/询盘对应**招标或国际资助项目**，须走「合规 > 价格」路线：

**3 个确认问题**
1. 此 BOQ 是否用于正在投标的 [项目名称]？贵司是主承包/分包？预计首批到货时间与分批节奏？
2. BOQ 同时含多套系统——贵司倾向 单一供应商打包 还是分别签约？我方 [核心品类] 全覆盖，缺口品类可由合作工厂配套（双证）。
3. 资助方对项目认证清单是否已锁定（[KS / ISO / ASTM / 区域标准 等]）？付款条件是 LC at sight、TT 还是分阶段？是否接受中国直发或经第三国转运？

**7 天行动清单**
- Day 1：邮件主题强调"[自有品牌] one-stop supply for [项目名] — Quote in 48h"；附项目常见文件清单（产品报告、工厂证书、合规声明）。
- Day 3：若已回复发初步报价 + 分包方案 + 工厂视频验厂邀请；若未回复改发"项目认证清单模板"以专业价值钩回。
- Day 7：抛钩子（首批订单 MOQ 优惠 + 优先排产）；邀视频会对齐规格与付款。

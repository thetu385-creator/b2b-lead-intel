# 各国/地区准入认证速查矩阵（通用版 + 行业补充区）

> 用途：阶段 5「准入门槛判定」对照表。标注「强制」= 进入该市场法定必须具备；「高关注」= 大买家/项目普遍要求，强烈建议具备。
> ⚠️ 本表仅列**跨行业通用高频认证**作为示例。各行业另有专属强制认证（建材/卫浴/食品接触/电子/医疗/玩具/机械等各不相同），请在下文「行业专属认证区」按贵司产品补充，否则阶段 5 判定会失真。

## 三、使用判读规则

1. 阶段 5 先定位客户**所在国/目标市场**，从上方匹配强制认证 → 若贵司暂缺该认证，标注「需补证方可成交」并评估补证周期/成本。
2. 工程类(Contractor/Builder)客户：除强制认证外，常额外要求**项目级检测报告、验厂、消防/安全证书**。
3. 经销商(Distributor)客户：优先看其已有认证覆盖能否"借力"，降低我方补证压力。
4. 中东/非洲部分市场无统一强制认证，以买家指定为准，阶段 5 需明确"买家要求"而非"法规强制"。

## 四、多边资助 / 政府招标项目认证原则（世行 / 亚开行 / 亚投行 / 各国 ODA）

- 这类项目通常要求供应商具备 **ISO 9001 体系 + 项目级检测报告 + 原产地证**；产品须满足项目 specs 指定的国际/区域标准。
- **通用铁律**：多边资助项目**文档合规 > 价格**；认证与检测报告须可追溯、批次化。缺证即标「需补证方可成交」，并评估补证周期是否赶得上招标窗口。
- 阶段 5 须请客户明确清单，并预留补证周期。
